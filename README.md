## ⚙️ Setting Up Your Environment

Because this website uses PHP, you must run it through a server. Most Windows users utilize XAMPP for this task.

1. Download and install XAMPP from the official Apache Friends website.
2. Open the XAMPP Control Panel once the installation finishes.
3. Click the "Start" button next to "Apache". 
4. If you see the status turn green, the server is active.
5. Navigate to your XAMPP installation folder (usually `C:\xampp`).
6. Open the `htdocs` folder. This is where you place your website files.
7. Move the extracted folder from the previous step into `htdocs`. Rename the folder to `tourism-site` for easy access.

## 🖥️ Running the Website

Once your server configuration is complete, follow these steps to use the interface:

1. Open your preferred web browser.
2. In the address bar, type `http://localhost/tourism-site/index.php` and press Enter.
3. The main page of the tourism website will load.
4. Browse the travel guides and destination sections to see the layout.
5. Click the chat icon in the bottom corner of the screen to open the chatbot.
6. Type a message into the dialogue box to test the response system.

## 🔍 Troubleshooting Common Issues

If the website does not load, verify these common items:

* **Check the Server:** Ensure the Apache module is running in the XAMPP control panel. If the status is red, the server failed to start, likely due to a port conflict.
* **File Path:** Ensure the folder name in `htdocs` matches exactly the spelling used in your browser URL.
* **Browser Cache:** Clear your browser cache if you made changes to the files and do not see the updates immediately.
* **File Permissions:** Ensure your user account has read access to the project folder.

## 📝 Configuration Tips

You can customize the website content without deep programming knowledge:

* **Changing Text:** Open any `.php` file in a simple text editor like Notepad. Look for text inside HTML tags like `<p>` or `<h1>`. Edit the text and save the file.
* **Updating Images:** Replace files in the `assets/images` directory. Ensure you use the same filenames and file types, such as .jpg or .png, to avoid breaking the links.
* **Chatbot Responses:** Navigate to the chatbot folder and look for a configuration file. You can modify existing responses to fit your specific tourism business needs.
